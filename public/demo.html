📋 Integration Code

To add this widget to your website, choose one of these methods:

Method 1: ID + Data Attribute (Recommended)

<script id="ersona-chat-widget" src="http://localhost:3000/chat-widget.js" data-company-id="YOUR_COMPANY_ID"></script>

Method 2: Data Attribute Only

<script src="http://localhost:3000/chat-widget.js" data-company-id="YOUR_COMPANY_ID"></script>

Method 3: URL Path (Legacy)

<script src="http://localhost:3000/widget/YOUR_COMPANY_ID"></script>

Note: Replace localhost:3000 with your actual domain and YOUR_COMPANY_ID with your actual company identifier in production
